# Обзор методов тактического планирования в RoboCup SSL

[![Build](https://github.com/Semelion/review_article_robocup_ssl/actions/workflows/build.yml/badge.svg)](https://github.com/Semelion/review_article_robocup_ssl/actions/workflows/build.yml)

Репозиторий обзорной статьи о методах принятия тактических решений и командного управления в RoboCup Small Size League.

В статье рассматриваются:

- архитектуры Skills--Tactics--Plays, иерархические и агентные подходы;
- распределение ролей между роботами;
- генерация, оценка и выбор передач;
- позиции поддержки, приём и перехват мяча;
- защита и учёт достижимости соперников;
- возможности и ограничения многоагентного обучения с подкреплением;
- применимость рассмотренных решений для стратегии на базе SPbUnited PAcmaCS.

Текущий текст является рабочим черновиком. В нём уже заполнены название, автор, классификационные коды, аннотация, ключевые слова, основные разделы, сравнительная таблица и первичная библиография. До финальной версии требуется уточнить требования издания, контактный email автора, состав авторов, формат библиографии и программу экспериментальной проверки будущего алгоритма.

## Автоматическая сборка PDF

GitHub Actions запускает сборку при каждом коммите в репозиторий, при создании или обновлении pull request, а также вручную через кнопку **Run workflow**.

Workflow выполняет следующие действия:

1. проверяет наличие Times New Roman и Courier New;
2. собирает `article.tex` с помощью Tectonic;
3. собирает контрольный пример из каталога `example/`;
4. публикует готовые `article.pdf` и `example.pdf` в разделе **Artifacts** соответствующего запуска.

Готовый PDF не хранится в Git: его можно скачать на странице [GitHub Actions](https://github.com/Semelion/review_article_robocup_ssl/actions) после успешного запуска.

## Локальная сборка

Требуется XeLaTeX или Tectonic.

```bash
make article
```

Результат будет записан в `build/article.pdf`.

Для одновременной сборки статьи и контрольного примера:

```bash
make all
```

## Основа оформления

LaTeX-класс и пример вёрстки основаны на проекте [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex). Класс `misisarticle.cls` распространяется на условиях LPPL 1.3c; текст лицензии находится в `LICENSE`.
